# Command-Line Unit Converter

A Python command-line application that converts temperature, distance, and weight units through an interactive terminal menu.

## Features

- 🌡 Temperature Conversion
  - Celsius → Fahrenheit
  - Fahrenheit → Celsius

- 📏 Distance Conversion
  - Kilometers → Miles
  - Miles → Kilometers

- ⚖ Weight Conversion
  - Kilograms → Pounds
  - Pounds → Kilograms

- ✅ User input validation
- ✅ Error handling using `try` and `except`
- ✅ Interactive command-line interface

## Technologies

- Python 3

## Skills Demonstrated

- Python fundamentals
- Conditional statements
- Loops
- Exception handling
- User input validation
- Command-line application development

## Running the Project

```bash
python unit_converter.py
```
